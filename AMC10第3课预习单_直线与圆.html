AMC 10 第 3 课 · 课前预习单

直线与圆（Lines & Circles） ｜ 2026-07-30 周四 19:00–20:30 ｜ 约 50–60 分钟

怎么用这份单子：不刷题，抓三件事 —— ① 复习第 2 课的斜率 / 直线（15 min）→ ② 预习截距和圆的标准方程（25 min）→ ③ 动手做 5 道小题检验真懂没懂（20 min）。 做完即可，卡住先标记，上课带着问题听。
1

复习第 2 课（15 min）· 确保地基稳

  • 斜率公式：m = (y₂ − y₁) / (x₂ − x₁)
  • 一次函数：y = kx + b（k = 斜率，b = y 轴截距）
  • 平行 ⇒ 斜率相等；垂直 ⇒ 斜率乘积 = −1
⚠ 佳琪薄弱点：独立把文字条件翻译成数学关系。复习时专门练：“点在 x 轴上 → y = 0”“直线平行 → 斜率相等”这类翻译。
2

预习新概念（25 min）· 明天要讲的

  • 截距：x 轴截距（令 y = 0）、y 轴截距（令 x = 0）
  • 直线方程几种形式：斜截式 y = mx + b ｜ 点斜式 y − y₁ = m(x − x₁) ｜ 一般式 Ax + By = C
  • 圆的标准方程：(x − h)² + (y − k)² = r²，圆心 (h, k)、半径 r
  • 直线与圆的位置关系（用圆心到直线的距离 d 判断）：
    d < r → 相交（2 个交点）｜ d = r → 相切（1 个交点）｜ d > r → 相离
3

动手做 5 道小题（20 min）

1过点 (2,3)、(4,7) 的直线，求斜率和方程。
2直线 y = 2x + 1 与 y = −½ x + 3 是否垂直？为什么？
3圆心 (1,−2)、半径 4 的圆，写出方程。
4点 (3,4) 是否在圆 x² + y² = 25 上？代入验证。
5直线 y = x + 1 与圆 (x − 1)² + (y − 2)² = 5 是相交 / 相切 / 相离？（提示：算圆心到直线的距离）

答案与提示

  1. 斜率 m = (7−3)/(4−2) = 2；方程 y − 3 = 2(x − 2) → y = 2x − 1。
  2. 是。斜率 2 与 −½ 乘积 = −1，故垂直。
  3. (x − 1)² + (y + 2)² = 16。（注意 y 坐标是 −2，故 y − (−2) = y + 2）
  4. 3² + 4² = 9 + 16 = 25 = r²，所以点在圆上。
  5. 圆心 (1,2) 到直线 y = x + 1（即 x − y + 1 = 0）的距离 d = |1 − 2 + 1| / √(1²+(−1)²) = 0/√2 = 0 < √5，故直线与圆相交（且过圆心）。

上课小目标（给佳琪）

  • 老师讲“圆方程”时，能马上说出圆心和半径；
  • 遇到“点在直线上 / 圆外”这类条件，能主动写成方程代入；
  • 把“图形观察”和“代数计算”两边对照看，不只会算不画、或只画不算。
