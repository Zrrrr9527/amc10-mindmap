圆的两种方程

标准方程 Standard

$$(x-h)^2 + (y-k)^2 = r^2$$圆心 (h, k) ，半径 r
  • 圆心在原点时简化为 x2 + y2 = r2
  • 给圆心和半径 → 直接写；给三点/直径 → 先求圆心半径

一般方程 General（需配方）

$$x^2 + y^2 + Dx + Ey + F = 0$$配方 → 圆心 $$\left(-\frac{D}{2},-\frac{E}{2}\right)$$，半径 $$\frac{1}{2}\sqrt{D^2+E^2-4F}$$
  • 判定是否成圆：需 D² + E² − 4F > 0
  • 题目常给一般式，第一步先配方拿圆心半径
2

三个距离公式（圆综合题的"弹药库"）

两点距离

$$d = \sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$$
  • 圆心到圆心、半径弦长都用它

点到直线距离

$$d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$$
  • ★切线判定的核心（见板块3）

平行线距离

$$d = \frac{|C_1-C_2|}{\sqrt{A^2+B^2}}$$
  • 两条平行切线间距 = 2r 常考
3

切线关系（两条铁律）

① 直线与圆相切 ⟺ 圆心到该直线的距离 = 半径
② 半径与切线在切点处互相垂直（半径 ⊥ 切线）
💡 核心转化套路（老师第 4–5 课重点）
看到 tangent / 相切，第一反应不是画图猜，而是：把"相切"翻译成"圆心到直线距离 = 半径"，再用点到直线距离公式列方程求解。图形条件 → 代数方程，是圆题稳定的解题路径。
4

圆与直线综合 · 固定解题流程

老师第 5 课强调：几何综合题不要凭直觉，按下面四步走，避免跳步失分。

  1. 标圆心和半径 — 先把圆方程写成标准式，明确 (h,k) 与 r
  2. 写切线 / 距离关系 — 相切就写"圆心到直线距离 = r"；相交/相离就写对应不等式
  3. 代入公式计算 — 点到直线距离公式代入，解出斜率 / 截距 / 参数
  4. 检查是否符合题目条件 — 验证解是否真满足几何意义（如半径>0、点在圆外等）
