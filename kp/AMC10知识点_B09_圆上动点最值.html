AMC10 · 圆的最值

圆上动点到定点的距离，最大、最小在哪一点？ 答案永远在连心线上。这一集把「为什么」画出来。

拖动圆上的青点 Q，或直接点圆周任意位置
2.60OP（固定）
1.00OQ = r（固定）
1.54PQ（在变）
三角形不等式把 PQ 夹住了：|OP − r| ≤ PQ ≤ OP + r
0 |OP−r| OP+r
结论

PO、OQ 长度都不变，只有 PQ 在动。三角形两边之差 ≤ 第三边 ≤ 两边之和 —— 所以 PQ 只能在一个区间里滑动，永远出不去。

最大值 = OP + r　·　最小值 = |OP − r|

识别信号：圆上动点 + 到某个定点的距离 + 求最大／最小 → 先把圆心和这个定点连起来。极值只可能出现在这条连心线与圆的两个交点上。
