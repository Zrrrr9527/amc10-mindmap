基础概念与 aₙ ↔ Sₙ 的关系

✅ 已学（课 5 · 课 7 作业）

四个基本概念

  • sequence 数列：按次序排列的一列数
  • term 项：aₙ 通项（第 n 项），a₁ 首项
  • 递推：用前一项（或几项）定义后一项
  • Sₙ 前 n 项和：Sₙ = a₁ + a₂ + … + aₙ

通项与前 n 项和的互求

$$a_1 = S_1,\qquad a_n = S_n - S_{n-1}\ \ (n\ge 2)$$已知 Sₙ 求 aₙ —— 第 7 课作业三类题型之一
  • ⚠️ n=1 必须单独验证：S₁ 未必满足通项公式

等差数列 Arithmetic —— 看「差」

✅ 已学（课 6 公式 · 课 7 性质）

核心公式

$$a_n = a_1 + (n-1)d$$公差 d = aₙ − aₙ₋₁（恒定）
$$S_n = \frac{n(a_1+a_n)}{2} = \frac{n\big[2a_1+(n-1)d\big]}{2}$$高斯首尾配对

四条性质（课 7 新讲）

① 下标关系

$$m+n=p+q \ \Longrightarrow\ a_m+a_n=a_p+a_q$$

② 等距项

  • aₖ, aₖ₊ₘ, aₖ₊₂ₘ … 仍成等差，公差 m·d

③ 分组和

  • Sₘ, S₂ₘ−Sₘ, S₃ₘ−S₂ₘ … 成等差，公差 m²d

④ 平均值

$$\frac{S_n}{n} = \frac{a_1+a_n}{2}$$前 n 项算术平均 = 首尾平均

等比数列 Geometric —— 看「比」

✅ 已学（课 7）

核心公式

$$a_n = a_1\cdot r^{\,n-1}$$公比 r = aₙ / aₙ₋₁（恒定）
$$S_n = \frac{a_1(1-r^n)}{1-r}\quad (r\neq 1)$$⚠️ r = 1 时退化为常数数列，Sₙ = n·a₁，单独算
$$S_\infty = \frac{a_1}{1-r}\quad (|r|<1)$$无穷等比和，仅 |r|<1 收敛

四条性质（课 7 新讲）

① 下标关系

$$m+n=p+q \ \Longrightarrow\ a_m\cdot a_n=a_p\cdot a_q$$

② 等距项

  • aₖ, aₖ₊ₘ, aₖ₊₂ₘ … 仍成等比，公比 rᵐ

③ 等距积

  • 与两端等距的两项之积相等（等比版「对称」）

④ 分组和

  • Sₘ, S₂ₘ−Sₘ, S₃ₘ−S₂ₘ … 成等比，公比 rᵐ

等差 vs 等比：先判断，再代公式

✅ 课 7 核心对比 · 当前主攻点

🔵 等差：看「差」

判据a₂−a₁ = a₃−a₂ = … = d
运算加 / 减（线性增长）
对称下标和相等 ⇒ 两项和相等（a₁+a₄ = a₂+a₃）
关键词每次多/少同样多、等间隔
VS

🟣 等比：看「比」

判据a₂/a₁ = a₃/a₂ = … = r
运算乘 / 除（指数增长·衰减）
对称下标和相等 ⇒ 两项积相等（a₁·a₄ = a₂·a₃）
关键词每次翻倍、减半、复利、百分比
🎯 三步判断法（第 7 课作业第 2 条要求的就是这个）
① 拿到数列先算相邻差——差恒定 ⇒ 等差，套 aₙ = a₁+(n−1)d；
② 差不恒定，再算相邻比——比恒定 ⇒ 等比，套 aₙ = a₁rⁿ⁻¹；
③ 差、比都不恒定，且已知 Sₙ ⇒ 走 aₙ = Sₙ − Sₙ₋₁ 这条路。
※ 先写判断、再写公式、最后代入数——这三步写全，步骤分就拿到了。

核心心法 · 易错提醒

① 「差」与「比」先分清：等差看差、等比看比。判断错了，后面全错——这是当前最该练的反应速度。
② 等比求和先查 r = 1：公式分母 (1−r) 在 r=1 时无意义，常数数列单独算；无穷和只在 |r|<1 时收敛。
③ 由 Sₙ 求 aₙ 必须验 n = 1：aₙ = Sₙ − Sₙ₋₁ 只对 n ≥ 2 成立，a₁ = S₁ 要单独代回检查。
④ 通项 ≠ 递推：通项是 aₙ 关于 n 的闭式；递推是前后项关系，求远项需先化通项或找周期。
💡 第 7 课老师的四条作业要求（照做即可，比多刷题管用）
1. 写出完整过程；2. 每题先判断类型（等差 / 等比 / aₙ 与 Sₙ 关系）；3. 先写公式，再代入数据；4. 做错或不会的题做标记，下节课优先讲评。
重点在第 2、3 条——它们练的就是「判断 → 选公式 → 规范代入」这条链。
