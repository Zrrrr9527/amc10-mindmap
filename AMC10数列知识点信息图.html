等差数列 Arithmetic（接下来深入）

通项公式

$$a_n = a_1 + (n-1)d$$公差 d，第 n 项由首项 + (n−1)个公差
  • 已知任意两项可反求 a₁ 与 d
  • 等差 ⇒ 相邻项差恒定

前 n 项和 Sₙ

$$S_n = \frac{n(a_1+a_n)}{2} = \frac{n\big[2a_1+(n-1)d\big]}{2}$$首尾配对 / 高斯求和
  • 中项性质：a,b,c 等差 ⇒ 2b = a + c
  • 对称项和相等
2

等比数列 Geometric（接下来深入）

通项公式

$$a_n = a_1 \cdot r^{\,n-1}$$公比 r，每项 = 前一项 × r
  • r = 1 时退化为常数数列（求和公式分母变 0，需单独讨论）

前 n 项和 + 无穷和

$$S_n = \frac{a_1(1-r^n)}{1-r} \quad (r\neq 1)$$无穷等比和（|r|<1）：$$S_\infty = \frac{a_1}{1-r}$$
  • |r|<1 时项数趋无穷和收敛
  • 增长/衰减、复利模型常用
3

递推与周期（接下来深入）

线性递推

$$a_n = p\,a_{n-1} + q$$待定系数 / 特征法求通项
  • 形如 aₙ − c = p(aₙ₋₁ − c)

裂项相消

$$\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$$求和时中间项抵消
  • telescoping 是 AMC 高频技巧

周期数列

$$a_{n+p} = a_n$$周期为 p，求大项下标取模
  • 模意义下常出现循环

AMC 常见数列题型

老师第 5 课指出：数列题主要考查"识别规律、建立通项、理解递推、求和转化"。

找规律写通项 求和转化（裂项 / 配对） 递归定义求值 周期性求大项下标 数字相关序列（digit sequences） 等差 / 等比综合应用 无穷等比和
5

核心心法 · 易错提醒

① 区分"通项公式"与"递推公式"：通项是 aₙ 关于 n 的闭式；递推是前后项关系，求具体项需递推展开或先化通项。
② 等比求和必查 r = 1 特例：公式分母 (1−r) 在 r=1 时无意义，常数数列单独算；无穷和只在 |r|<1 时收敛。
③ 大下标不硬算：遇递推或周期，先找周期 p / 模规律，用 n mod p 化简到小项下标再求。
💡 学习顺序建议
先吃透等差 / 等比的通项 + 求和两套公式（含无穷和），再攻递推（线性递推、裂项），最后用周期与模收口。每学一个公式，配 2–3 道 AMC 小题验证"代入不跳步"。
